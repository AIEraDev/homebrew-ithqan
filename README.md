# homebrew-ithqan

Homebrew tap for [Ithqan](https://github.com/AIEraDev/Ithqan) — a local-first Quran memorization review companion.

## Install

```bash
brew tap aieradev/ithqan
brew install --cask ithqan
```

## Update

```bash
brew update
brew upgrade --cask ithqan
```

## Uninstall

```bash
brew uninstall --cask ithqan
brew untap aieradev/ithqan
```
